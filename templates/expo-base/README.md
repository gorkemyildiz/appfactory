# Expo başlangıç şablonu

React Native, Expo SDK 57, Expo Router ve TypeScript. Ana ekran, kayıt oluşturma, ayrıntı düzenleme ve ayarlar ekranları Türkçedir. Kayıtlar AsyncStorage ile cihazda saklanır.

Bu klasör generator girdisidir. Üretilen projede app.json ve proje bilgileri tamamlanır. Burada doğrudan bağımlılık kurmayın. Fikre özel kod üretimi henüz yoktur.
